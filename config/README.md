# Main parameter description

dataset_name: Dataset name

classnum: Number of cell types

k_for_anchor: Number of neighbors selected for each cell to choose anchor cells

coefficient_neighbor: The same label ratio required to retain a cell as an anchor cell

coefficient_prune: The density threshold for retaining anchor cells

top_markers: The number of differentially expressed genes selected

n: Number of neighbors selected for each cell in contrastive learning model

c: Number of positive examples selected

T: Temperature coefficient
